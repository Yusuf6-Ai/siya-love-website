SIYA WEBSITE UPDATE

Use this update with your EXISTING website folder so your existing images stay safe.

1. Open your existing "siya_love_website" folder.
2. Copy these 4 files from this update into that folder:
   - index.html (replace the old one)
   - style.css (replace the old one)
   - chuchi.html (new file)
   - memories.html (new file)
3. Click Replace when Windows asks.
4. DO NOT delete or replace your existing "images" folder.
5. Open index.html and refresh with Ctrl + F5.

The special pages use your existing image names:
- images/YOUR_CHUCHI.jpg
- images/SIYA_MAD.jpg
- images/HAM_SE_NA_HOTA.jpg
